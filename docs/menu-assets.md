# Menu photographs

The menu catalog in `lib/menu-data.ts` contains all 155 PNG photographs supplied in the local `MENU TOKI` folder, preserving its 20 categories. The website serves optimized WebP copies from `public/menu/dishes/`; the source folder is unchanged.

Categories follow starters (cold, hot, fried), soups, sharing platters, sushi, grilled and cooked mains, then noodle and rice accompaniments. “New” badges are limited to the three source images explicitly labeled “Novidade”.

Three source filenames in `Tataki e Carpaccio` are not official menu names. These use descriptive captions pending owner-supplied names:

| Source | Caption |
| --- | --- |
| `6.png` | Tataki com molho |
| `Four richly seared tuna pieces.png` | Tataki de atum |
| `Four seared fish on a ceramic plate.png` | Peixe braseado |

No prices, ingredient lists, portion counts, allergen claims, or unavailable categories were inferred from the photographs. Portuguese names follow the filenames with minor spelling and accent corrections; English captions support the existing language switch.
